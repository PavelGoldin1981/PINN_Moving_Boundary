# PINN with Moving Boundary

This repository contains a Python script used in the study of a
physics-informed neural network (PINN) for a diffusion problem
with a moving boundary (Stefan-type problem).

## Description

The script implements a PINN model for a diffusion-controlled
droplet growth problem with a time-dependent boundary.

## Usage

Run the script with:

```bash
python PINN_droplet_Vasilev_learning.py
